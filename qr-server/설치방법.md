# QR 사진 전달 — 설치 방법 (Google Drive + Apps Script)

완성 사진을 학교 Google Drive 에 올리고, 그 주소를 QR 로 보여줘 학생·학부모가 휴대폰으로 가져가게 하는 기능입니다.
한 번만 설정하면 됩니다 (약 5분).

> **이미 설정되어 있습니다.** 학교 계정으로 배포한 주소가 `index.html` 의 `DEFAULTS.qrUrl` 에 기본값으로 들어 있어 아무 설정 없이 QR 이 뜹니다. 아래는 다른 계정으로 새로 배포하거나 문제가 생겼을 때 참고하세요.

## 1. Apps Script 만들기
1. 학교 Google 계정으로 로그인한 뒤 https://script.google.com 접속 → **새 프로젝트**
2. 편집기에 있는 내용을 모두 지우고 `Code.gs` 파일 내용을 그대로 붙여넣기 → 저장(Ctrl+S). 프로젝트 이름은 "네컷 QR" 등 아무거나
3. 위쪽 함수 선택 상자에서 `removeCleanupTrigger` 선택 → **실행** (폴더를 만들고, 예전 자동 삭제 예약이 있으면 지움)
   - "승인 필요" 창 → 권한 검토 → 계정 선택 → (안전하지 않음 경고가 나오면) 고급 → "프로젝트로 이동" → 허용
   - 실행 로그에 "자동 삭제 트리거 … 지움" 이 뜨면 성공. Drive 에 `네컷사진` 폴더가 생깁니다.

## 2. 웹앱으로 배포
1. 오른쪽 위 **배포 → 새 배포**
2. 톱니바퀴(유형 선택) → **웹 앱**
3. 설정
   - 설명: 아무거나
   - **다음 사용자 인증 정보로 실행: 나**
   - **액세스 권한이 있는 사용자: 모든 사용자** ← 중요 (촬영 PC 가 로그인 없이 보내야 함)
4. **배포** → 나오는 **웹 앱 URL** (`https://script.google.com/macros/s/.../exec`) 복사

## 3. 네컷 앱에 연결
1. 네컷 앱에서 `S` 키 → 설정
2. **QR 업로드 주소** 칸에 위 URL 붙여넣기 → **연결 확인** 버튼 → "연결 성공" 확인 → 저장
3. 이후 완성 화면에 **📱 휴대폰으로 가져가기** QR 이 표시됩니다 (촬영 PC 에 인터넷이 있어야 함)

## 4. 휴대폰 앱 "사진 제출" 번호 (2026-09-22 추가) — **다시 배포 필요**
휴대폰 앱에서 **사진 제출**을 누르면 서버가 그날 1번부터 순서대로 번호를 매겨 `네컷사진` 폴더에 `0922-037_2장.jpg`(날짜-번호_출력매수) 로 저장하고, 학생 화면에 **37번** 을 보여줍니다. 선생님은 드라이브에서 번호로 찾아 출력하면 됩니다.
번호를 서버가 매겨야 여러 휴대폰이 동시에 써도 겹치지 않으므로 **한 번 다시 배포**하세요 (약 2분, URL 은 그대로). 재배포 전에는 각 휴대폰이 스스로 번호를 매겨(겹칠 수 있음) 동작합니다.
같은 배포에 (선택) PC 자동 인쇄 대기열(`?action=list / get / done`, `인쇄대기.bat`)도 들어 있습니다.
1. https://script.google.com → 기존 프로젝트 열기
2. 편집기 내용을 지우고 새 `Code.gs` 내용을 붙여넣기 → 저장
3. **배포 → 배포 관리 → 연필(수정) → 버전: 새 버전 → 배포**
4. 확인: 휴대폰에서 사진 제출 → 드라이브 `네컷사진` 폴더에 `0922-001_1장.jpg` 처럼 저장되면 성공 (재배포 전이면 이름은 같지만 번호가 폰마다 따로 매겨짐)
5. (선택) 자동 인쇄를 쓰려면 PC `인쇄대기.bat` 을 켜고 휴대폰 고급 설정에서 **PC 자동 인쇄 대기열로 보내기** 켜기
- 그때 휴대폰이 보낸 사진은 Drive `네컷사진` 폴더에 `print_…_x매수.jpg` 로 저장되고, PC 가 인쇄한 뒤 `done_…` 으로 이름이 바뀝니다. 보관·삭제 규칙은 QR 사진과 같습니다.

## 동작 / 개인정보
- 사진은 학교 계정 Drive 의 `네컷사진` 폴더에만 저장됩니다. 외부 업체 서버에는 올라가지 않습니다.
- 공유는 "링크가 있는 사람은 볼 수 있음" 이고, 주소는 추측할 수 없는 Drive ID 라 QR 없이는 찾을 수 없습니다.
- 사진은 **자동으로 지워지지 않습니다** (2026-09-22 부터). 정리가 필요하면 Drive 의 `네컷사진` 폴더에서 직접 지우세요. 예전에 등록한 "매일 03시 자동 삭제" 예약은 편집기에서 `removeCleanupTrigger` 를 한 번 실행하면 사라집니다 (또는 왼쪽 ⏰ 트리거 메뉴에서 삭제).
- 업로드가 실패해도(인터넷 끊김 등) 인쇄는 그대로 됩니다. QR 자리에 "업로드 실패" 만 표시됩니다.

## 문제 해결
- **"연결 확인" 이 실패**: 배포할 때 "액세스: 모든 사용자" 인지, URL 이 `/exec` 로 끝나는지 확인. `/dev` 주소는 안 됩니다.
- **휴대폰에서 열면 "액세스 권한 필요"**: 학교 Workspace 관리자가 외부 공유(링크 공유)를 막아둔 경우입니다. 관리 콘솔에서 Drive 외부 공유를 허용하거나, 정보부에 문의하세요.
- **코드를 고친 뒤 반영이 안 됨**: 저장만으로는 안 되고 **배포 → 배포 관리 → 연필 → 버전: 새 버전 → 배포** 를 해야 합니다. URL 은 그대로 유지됩니다.
