# 모덕 네컷 휴대폰판 — 사용 설명서

휴대폰으로 찍고 꾸민 사진이 학교 구글 드라이브 **네컷사진** 폴더에 올라갑니다. 출력은 선생님이 드라이브에서 직접 합니다. PC 부스(`index.html`)와 프레임·스티커·인쇄 규격이 같습니다.

주소: **https://junho1-commits.github.io/modeok-4cut/mobile/**

## 준비물
- 휴대폰 (아이폰 사파리 / 안드로이드 크롬) + 인터넷(학교 Wi-Fi 또는 데이터)
- 출력용 PC + SELPHY CP1500 + 인터넷 (드라이브 열기용). 따로 설치할 것 없음

## 휴대폰 (선생님이 한 번 세팅)
1. 위 주소 접속 → 공유 버튼 → **홈 화면에 추가** 하면 앱처럼 열립니다 (추천)
2. 카메라 허용 물어보면 **허용**
3. 세팅 화면에서 학교/행사 이름 · 하단 문구 · 글꼴(4종) · 날짜 · 촬영 장수 · 프레임 고정 · 스티커 첫 화면을 정합니다. 미리보기가 같이 바뀌고, 설정은 저장되어 다음에도 그대로예요.
4. 미리보기 옆에 **✅ 드라이브 연결됨** 이 떠야 합니다 (인터넷 확인)
5. **▶ 부스 시작**

## 학생 (반복)
1. 카운트다운(기본 3초) 촬영 — 큰 📸 버튼을 누르면 바로 찍힘, 🔄 로 앞/뒤 카메라 전환
2. (6·8장이면) 마음에 드는 4장을 순서대로 터치
3. 프레임을 옆으로 넘겨 고르기 (세팅에서 고정했으면 생략)
4. 꾸미기 — **시간제한 없음**
   - 아래 줄의 스티커를 누르면 사진에 붙음 (줄을 옆으로 밀어 더 보기, 위 탭으로 묶음 바꾸기)
   - 줄 맨 앞 **✏️ 문구** → 글을 입력하면 문구 스티커가 붙음
   - 한 손가락으로 끌기 → 옮기기 / 두 손가락으로 벌리기·오므리기 → 크기, 돌리기 → 회전 / 선택 테두리 위 ↻ 손잡이를 끌어도 회전
   - 오른쪽 위 **스티커 ▾** 를 누르면 스티커 줄이 접히고 사진이 크게 보여 손으로 다루기 쉬움 (다시 누르면 펼침)
   - 위쪽 **✕ 지우기**(선택한 것) / **🗑 전체**, 문구 글꼴은 위쪽 선택 상자
5. **완성하기** → 몇 장 뽑을지(1~4장) 터치 → "✅ 드라이브에 올라갔어요"
   - **💾 폰에 저장** 을 누르면 이 휴대폰 사진첩에 저장(또는 카톡 등으로 바로 보내기)
   - 10초 뒤 다음 친구 촬영으로 자동 이동 (또는 **다음 친구 →**)
   - 보내기가 실패하면(인터넷 끊김) **다시 보내기**

## 선생님 출력 (PC)
1. PC 에서 drive.google.com → 학교 계정 → **네컷사진** 폴더
2. 파일 이름이 `네컷_날짜시간_2장.jpg` 처럼 되어 있어요 → 끝의 **N장** 만큼 출력
3. 파일 더블클릭 → 다운로드 → Windows 사진 앱에서 열기 → 인쇄(Ctrl+P) → 프린터 **Canon SELPHY CP1500**, 용지 **엽서**, **여백 없음**, 매수 N → 인쇄
   - 또는 PC 부스 `index.html` 의 고급 설정처럼 드라이버 기본값을 엽서·여백 없음으로 맞춰 두면 인쇄 창에서 바로 인쇄
4. 사진은 7일 뒤 자동 삭제됩니다 (QR 사진과 같은 규칙). 남기려면 다른 폴더로 옮기기

## (선택) PC 자동 인쇄
사람이 없어도 자동으로 뽑고 싶으면 `인쇄대기.bat`(print-station/) 을 PC 에 켜 두면 됩니다. 이 경우
- `qr-server/설치방법.md` 4번대로 Apps Script 를 다시 배포하고
- 휴대폰 고급 설정에서 **PC 자동 인쇄 대기열로 보내기** 를 켭니다
보통은 필요 없습니다.

## 고급 설정 (세팅 화면 맨 아래 버튼)
- 카메라: 앞(셀카, 거울처럼) / 뒤(화질 좋음, 다른 사람이 찍어줄 때)
- 카운트다운 초
- 드라이브 업로드 주소: PC 부스의 QR 업로드 주소와 같은 Apps Script 주소. 기본값이 들어 있음

## 알아둘 것
- 휴대폰판은 **인터넷이 있어야** 합니다 (앱 열기, 사진 올리기).
- 글꼴은 용량 때문에 4종(주아·나눔손글씨 펜·개구쟁이·도현)만 들어 있습니다.
- 카메라 화면의 가운데 세로 부분이 사진 칸(535×690)에 들어갑니다. 화면에 보이는 그대로 찍힙니다.
- 아이폰: 화면 자동 잠금이 짧으면 촬영 중 꺼질 수 있어요. 설정 → 디스플레이 → 자동 잠금을 늘려 두세요.

## 문제 해결
- **카메라가 안 켜짐**: 사이트 설정에서 카메라 허용 확인. 다른 앱(카메라, 줌)이 카메라를 쓰고 있으면 닫기. 홈 화면 추가 앱에서 안 되면 브라우저로 직접 열어 보기
- **드라이브에 안 올라감**: 인터넷 확인 → 다시 보내기. 계속 실패하면 세팅 화면의 연결 상태와 고급 설정의 주소 확인
